STLF Traction Control Components

Caterpillar Inc., Technology Division • Aug 2025 – Present

As part of the STLF programme within Caterpillar's Technology Division, I architect situational speed target generators and wheel-level control logic for traction control. The work involves multi-rate integration for vehicle sensing and validation through Dynasty plant testing.

Key Contributions

  • Architected situational speed target generators and wheel-level control logic for traction control in Simulink.
  • Developed multi-rate integration approach for vehicle sensing (IMU + wheel speed sensors) targeting ECM/ECU deployment.
  • Generated embedded C from Simulink models for engine control module deployment.
  • Validated and tuned traction speed estimation and control using Dynasty plant testing; reduced oscillations in the control loop.

Skills & Tools

  • Control theory & traction dynamics
  • Model-based development in Simulink
  • Embedded C programming & code generation
  • SITL/HITL testing and validation
