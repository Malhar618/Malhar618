STLF Traction Control Components

Systems Technology Leadership Forum • 2025

Through the Systems Technology Leadership Forum (STLF) programme I collaborated with engineers and fellow researchers to develop a common traction‑control software library. The goal was to standardise control algorithms and interface definitions across multiple heavy‑equipment platforms.

Key Contributions

  • Defined software interfaces and message contracts for traction controllers to enable interoperability between different hardware platforms.
  • Refactored traction‑control algorithms in Simulink and C to improve robustness and modularity.
  • Developed unit‑test suites to validate controller behaviour under varying slip conditions and payloads.
  • Documented the architecture and contributed to an implementation guide for participating teams.

Skills & Tools

  • Control theory & traction dynamics
  • Model‑based development in Simulink
  • C programming & software architecture
  • Collaborative documentation
