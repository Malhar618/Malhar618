GoAERO @ Virginia Tech

Avionics architecture for a rescue UAV concept.

Team lead work focused on ROS 2 communication, flight-stack integration, sensor interfaces, onboard compute, and simulation-to-flight validation.

Role

I led the avionics and programming workstream for GoAERO @ Virginia Tech, coordinating software architecture and integration planning with other aircraft subteams.

  • Defined ROS 2 messaging and interface expectations between flight stack, sensors, and onboard compute.
  • Built a validation path using SITL/HITL, telemetry, command pipelines, and staged integration milestones.
  • Contributed to the preliminary design review package for a rescue UAV concept.
  • Supported a multidisciplinary team that received a NASA University Innovation Prize valued at $30K.

Engineering Framing

The main technical challenge was not just selecting avionics components. It was making sure interfaces, sensors, control loops, compute budgets, failure modes, and test procedures could be understood by the entire team before hardware integration.
