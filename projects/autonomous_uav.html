Personal project · May - Aug 2024

Depth-based mapping, obstacle avoidance, and flight-control integration.

A quadrotor built around Jetson Nano, Intel RealSense D455, Python/OpenCV, MAVSDK, and simulation-first validation.

Background

I wanted to run autonomy code against real sensors, a real flight controller, and the limits of a small airframe, not just a desktop simulation.

Implementation

  • Integrated a Jetson Nano and Intel RealSense D455 for real-time depth perception.
  • Used Python/OpenCV for depth-based mapping, obstacle detection, and target tracking, with YOLOv5 models for onboard object detection.
  • Connected autonomy logic to MAVSDK flight-control interfaces and validated behavior through jMAVSim plus SITL/HITL workflows before flight testing.
