Autonomous UAV

Depth-based mapping, obstacle avoidance, and flight-control integration.

A quadrotor project built around Jetson Nano, Intel RealSense D455, Python/OpenCV, MAVSDK, and simulation-first validation.

Problem

I wanted a project that forced autonomy code to interact with real sensors, flight-control APIs, and the constraints of a small airframe instead of stopping at a desktop simulation.

Implementation

  • Integrated a Jetson Nano and Intel RealSense D455 for real-time depth perception.
  • Used Python/OpenCV for depth-based mapping, obstacle detection, target tracking, and simple gesture-recognition commands.
  • Connected autonomy logic to MAVSDK flight-control interfaces and validated behavior through JMavSim plus SITL/HITL workflows before flight testing.
  • Modeled the drone in CAD and used basic airflow/thermal reasoning to understand stability and hardware placement constraints.

Why It Matters

This project connects directly to the internship roles I am targeting: perception and autonomy code has to be validated against flight-control behavior, compute limits, sensor placement, and repeatable test conditions.
